description: Prepare a release if the gates pass (usage /release 0.1.0)
---
Prepare release $ARGUMENTS. Proceed only if docs/AUDIT.md has no open critical or high finding and docs/PARITY.md has no unapproved DEVIATION and no missing MUST; otherwise STOP and list the blockers. Then: bump the version (semver) across the workspace, write CHANGELOG.md, write docs/MIGRATION.md (how to move from the original software: data import/export formats and steps from spec/02-data-model.md, plus behavior differences from approved deviations), write docs/RELEASE_CHECKLIST.md, make sure README.md is current, run the full toolchain and a clean `cargo build --release --locked`, build the UI and check its bundle budget, run the Playwright suite and attach the axe summary, run /ui-parity if the original is available, build the container image if the plan has one, generate checksums for the artifacts, create and push the git tag if a remote is configured. Verify the license of every asset, font and vendored component before publishing, and check BoardUI's redistribution terms. Update docs/STATE.md.
