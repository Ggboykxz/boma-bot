# Before-M5 completion — master plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) to implement this plan task-by-task. Do not start Phase 2/3 tasks before Phase 1 is green.
>
> **Executing-plans:** if run in this session without subagents, execute Phase 1 with `superpowers:executing-plans` and re-scan Phase 2/3 files when Phase 1 is complete.

**Goal:** close the open acceptance criteria of M0–M4 (REQ-019, REQ-022), the in-scope defect obligations (`spec/05-known-defects.md`, D-01..D-09), and a full agent tool loop behind the `ModelProvider` port — scripted deterministic tests first, then a BYOK/OpenAI-compatible adapter over the same port.

**Architecture:** `app::worker` drives a provider-turn loop. `ModelProvider::complete` returns a typed turn (`Chunks` or `ToolCalls`). A `ToolGate` dispatches only catalogued tools. Read effects execute; write/spend create a pending card and suspend the run; the existing card-answer path records the idempotent effect and resumes. Helper delegation is a tool (`delegate.helper`) that spawns a `HelperResult` run; completion of the helper writes a structured `role=tool` result on the parent thread and resumes the parent (REQ-019). Memory is passed into the provider request as typed context (REQ-022).

**Tech:** Rust (`tokio`, `axum`, `sqlx`, `thiserror`), existing worker/usecase/store patterns. No new dependency for the loop. BYOK adapter behind a recorded fixture, no live network in tests.

**Spec:** `docs/superpowers/specs/2026-11-13-before-m5-design.md` (approved via "make the best choices").

## Global constraints

- REQ / defect id in the *test name* (`req_019…`, `d_01…`).
- Helios gates per push: fmt, clippy `-D warnings`, nextest, `cargo deny`, `cargo machete`, `trace_check.py` (≤40), `secret_scan`.
- No secrets, no live provider keys in tests/CI/logs.
- Effects exactly-once (`tool:{run_id}:{call_id}`); no lock across `.await`; bounded streaming; typed config.
- D-03/D-05/D-06 land with M5/M6/M7. Record this in `docs/STATE.md`.
